## How to use Dekho Prime (Web)

### 1. Open the site

Go to **[dekhoprime.live](https://dekhoprime.live)** on Chrome, Firefox, Edge, or Safari.

### 2. Sign in

Tap **Sign in** and continue with **Google**. Signing in unlocks movies, shows, Live TV, events, and synced history.

### 3. Explore the main sections

| Menu | Use it for |
| --- | --- |
| **Home** | Highlights, continue watching, and discovery |
| **Movies** | Browse and play movies |
| **Shows** | TV series and episodes |
| **Live TV** | Live channels — search by name, language, or category |
| **Anime** | Anime titles (via More menu on mobile) |
| **Discover** | Trending picks |
| **Events** | Sports schedule → open a match → jump to Live TV |
| **Settings** | Theme, language, and preferences |

### 4. Watch Live TV like a pro

1. Open **Live TV**.
2. Filter by group or search for a channel.
3. Tap a channel to play.
4. If a server fails, Dekho Prime **auto-switches** to another source.
5. Use the **Server** menu to pick a source manually — badges show quality % and failed servers.
6. Channels that fully fail stay marked **Offline** for a short time so you don’t keep retrying dead streams.

### 5. Follow live sports

1. Open **Events**.
2. Pick today’s match (football, cricket, and more).
3. See kickoff time and broadcaster list.
4. Jump straight into matching Live TV when available.

## How to install the Android apps

You need **two different APKs**:

| Device | Package | Download |
| --- | --- | --- |
| **Phone / tablet** | Dekho Prime (mobile) | [dekho-prime-mobile.apk](https://github.com/imShakil/tvlink/releases/latest/download/dekho-prime-mobile.apk) |
| **Android TV / Google TV** | Dekho Prime TV | [dekho-prime-tv.apk](https://github.com/imShakil/tvlink/releases/latest/download/dekho-prime-tv.apk) |

Or use the in-app download page: **[dekhoprime.live/download](https://dekhoprime.live/download)**  
Also on **[APKPure](https://apkpure.com/p/com.imshakil.bdiptv)** and **[GitHub Releases](https://github.com/imShakil/tvlink/releases/latest)**.

> **Tip:** Do **not** install the phone APK on a TV box (or the TV APK on a phone). Leanback / remote navigation only works correctly with the matching build.

### Install on phone or tablet

1. Download **dekho-prime-mobile.apk**.
2. Open the file from your browser Downloads or a file manager.
3. If Android asks, allow **Install unknown apps** for that browser/file manager (this install only).
4. Tap **Install** → **Open**.
5. Sign in with Google and start streaming.

**Requirements:** Android **8.0 (Oreo)** or newer.

### Install on Android TV / Google TV

1. Download **dekho-prime-tv.apk** on a phone, PC, or directly on the TV browser.
2. Transfer to the TV (USB stick, file manager, Send files, or download in TV browser).
3. Open the APK with a file manager on the TV.
4. Allow installs from that source if prompted.
5. Install → find **Dekho Prime TV** on the home row / Apps.
6. Use the remote (D-pad) to navigate and sign in.

**Requirements:** Android TV / Google TV with Leanback (Android 8.0+).

## FAQ

**Is Dekho Prime free?**  
Yes — use it free on web and with the official APKs.

**Why won’t a Live TV channel play?**  
Try another server from the Server menu. Failed sources are skipped for a while; use **Retry all servers** if you want to force another attempt.

**Phone app on my TV doesn’t feel right.**  
Install the **TV APK**, not the mobile one.

**Do I need an account?**  
Sign-in unlocks the full library and syncs history across devices.
