## ডেখো প্রাইম কীভাবে ব্যবহার করবেন (ওয়েব)

### ১. সাইট খুলুন

Chrome, Firefox, Edge বা Safari-এ **[dekhoprime.live](https://dekhoprime.live)** খুলুন।

### ২. সাইন ইন করুন

**Sign in** ট্যাপ করে **Google**-এর মাধ্যমে চালিয়ে যান। সাইন ইন করলে মুভি, শো, লাইভ টিভি, ইভেন্ট এবং সিঙ্কড হিস্ট্রি আনলক হয়।

### ৩. মূল সেকশনগুলো ঘুরে দেখুন

| মেনু | কী কাজে লাগে |
| --- | --- |
| **Home** | হাইলাইট, কন্টিনিউ ওয়াচিং, ডিসকভারি |
| **Movies** | মুভি ব্রাউজ ও প্লে |
| **Shows** | টিভি সিরিজ ও এপিসোড |
| **Live TV** | লাইভ চ্যানেল — নাম, ভাষা বা ক্যাটাগরি দিয়ে সার্চ |
| **Anime** | অ্যানিমে (মোবাইলে More মেনু থেকে) |
| **Discover** | ট্রেন্ডিং পিক |
| **Events** | স্পোর্টস সূচি → ম্যাচ খুলুন → লাইভ টিভিতে যান |
| **Settings** | থিম, ভাষা ও প্রেফারেন্স |

### ৪. লাইভ টিভি স্মার্টভাবে দেখুন

1. **Live TV** খুলুন।
2. গ্রুপ ফিল্টার করুন বা চ্যানেল সার্চ করুন।
3. চ্যানেলে ট্যাপ করে প্লে করুন।
4. কোনো সার্ভার ফেল করলে ডেখো প্রাইম **অটোমেটিক অন্য সোর্সে** সুইচ করে।
5. **Server** মেনু থেকে ম্যানুয়ালি সোর্স বেছে নিন — ব্যাজে কোয়ালিটি % ও ফেইল্ড সার্ভার দেখায়।
6. সব সোর্স ফেল হলে চ্যানেল কিছুক্ষণ **Offline** হিসেবে মার্ক থাকে, যাতে বারবার ডেড স্ট্রিম চেষ্টা না হয়।

### ৫. লাইভ স্পোর্টস ফলো করুন

1. **Events** খুলুন।
2. আজকের ম্যাচ বেছে নিন (ফুটবল, ক্রিকেট ইত্যাদি)।
3. কিকঅফ সময় ও ব্রডকাস্টার লিস্ট দেখুন।
4. উপলব্ধ থাকলে সরাসরি ম্যাচিং লাইভ টিভিতে যান।

2. টিভিতে ট্রান্সফার করুন (USB, ফাইল ম্যানেজার, Send files, বা টিভি ব্রাউজারে ডাউনলোড)।
3. টিভির ফাইল ম্যানেজার দিয়ে APK খুলুন।
4. চাইলে সেই সোর্স থেকে ইনস্টলের অনুমতি দিন।
5. ইনস্টল শেষে হোম রো / Apps-এ **Dekho Prime TV** খুঁজুন।
6. রিমোট (D-pad) দিয়ে নেভিগেট করে সাইন ইন করুন।
